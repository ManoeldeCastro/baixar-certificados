# C# Formatting Rules for BrokerServicos

Apply to all C# code generated by agents in this workspace.

- Always break parameters/arguments onto separate lines when they span multiple lines.
- One parameter per line when broken; indent parameters by 4 spaces.
- Method calls with multiple arguments should use one argument per line when broken.
- For class/interface inheritance, place `:` on the next line aligned:
  public sealed class X
      : BaseClass
- Keep `using` order: System.* first, then project namespaces.
- Keep blank lines between logical blocks; do not collapse them.
